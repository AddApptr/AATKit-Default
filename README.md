# AATKit-Default

The default AATKit distribution as a Swift Package: AATKit together with every ad network in the default set. Add this package instead of picking the adapter packages one by one.

* For more information about integration steps, please refer to the [integration documentation](https://docs.gravite.net/aatkit/ios/docs/documentation/aatkit/)

## Important Note
You have to add -ObjC in your build settings by following these steps:

* Click on the project navigator
* Click on your target and build settings
* Search for "other linker flags"
* Add "-ObjC"
